# 연수자료 만들기

교사 연수용 **웹 발표자료**를 기획하고, 밝은 바탕과 굵은 한국어 글꼴·색 테두리 디자인으로 제작·검증·배포하는 AI 에이전트 스킬입니다.

자료를 먼저 읽고 어울리는 기능을 체험으로 추천합니다. 사용자가 고르면 전체 페이지 구성을 확인받은 뒤 제작합니다. 기능 목록이나 긴 기획서를 사용자가 미리 작성할 필요는 없습니다.

**연수 장면 실험실**에는 클릭 애니메이션, 움직이는 제목, 모션 그래픽, 이미지 슬라이드, 전후 비교, 부분 확대, 뒤집기, 클릭 지점, 진행 조작, 스크롤, 입체 효과, 배치 전환, 선택 분기, 설문, 단어 모으기, 순서 변경의 16가지 예시가 있습니다.

```sh
node scripts/preview-scenes.mjs --dest ./scene-preview --serve --recommend reveal,compare,motion
```

설치·계정 없이 출력된 URL에서 체험합니다(Node 필요). 설문·단어는 한 브라우저 예시이며 여러 기기의 실제 집계에는 서버 연결이 필요합니다. 선택은 복사/JSON으로 전달할 수 있고, 전체 구성안 승인을 대신하지 않습니다. [자료 기반 추천·선택 흐름](references/scene-discovery.md) · [CSS 효과 조사와 공식 출처](references/scene-effects-research.md)

[이전 정적 템플릿 체험](https://vanollim-deck-harness-20261023.hhj96916.workers.dev/) · [스킬 지침](SKILL.md) · [ZIP 다운로드](https://github.com/Jun268-96/teacher-workshop-web-deck/archive/refs/heads/main.zip)

## 사용하기

스킬을 지원하는 에이전트에 이 저장소를 설치하거나, 저장소를 읽을 수 있는 도구에 다음처럼 요청하세요.

> https://github.com/Jun268-96/teacher-workshop-web-deck 의 SKILL.md를 읽고, 내 자료로 교사 연수용 웹 발표자료를 만들어줘. 필요한 질문을 먼저 하고, 도구가 없으면 설치 여부를 물어봐. 검증과 배포까지 진행해줘.

저장소 링크를 읽을 수 없는 환경에서는 ZIP을 내려받아 첨부하고 `SKILL.md`부터 읽도록 요청할 수 있습니다. 실제 파일 실행·브라우저 검증·배포 가능 범위는 사용하는 도구의 권한에 따라 달라집니다.

## 두 가지 입력 방식

- **주제부터**: 주제와 청중·시간·실습 여부를 바탕으로 내용을 조사하고 새 연수를 구성합니다.
- **기존 자료부터**: PPT·PDF·대본·기존 연수 사이트의 내용과 의도를 파악해 웹 발표자료로 만듭니다. 원본 흐름 유지/재구성 방향을 확인하고, 전체 페이지 구성안을 승인받은 뒤 제작합니다. 원본과 새 페이지·발표자 노트를 대조해 누락도 확인합니다.

기존 자료가 있다면 다음처럼 요청하세요.

> 이 연수자료를 바탕으로 밝은 바탕과 색 테두리의 웹 발표자료로 만들어줘. 내용은 유지하되 화면은 간결하게 하고, 제작 전에 전체 페이지 구성부터 보여줘.

파일을 읽을 수 있는 도구와 권한이 필요합니다. 원본 파일은 보존하며, 읽지 못한 범위는 확인하지 못했다고 표시합니다.

## 기본 원칙

- 실습·참여 활동 포함 여부와 반드시 포함할 내용은 답이 없으면 꼭 질문합니다. 이미 확인한 답은 반복해서 묻지 않습니다.

- 요청이 짧으면 필요한 맥락을 확인한 뒤 공개 출처와 실제 사례를 조사해 내용을 구체화합니다.
- 원본 시간표·타이머·과거 회차의 대화를 이번 연수의 시간 조건으로 자동 승계하지 않습니다. 현재 시간이 미정이면 내용 중심으로 구성하며, 임의의 제한 때문에 활동을 줄이지 않습니다. [시간의 출처와 적용 범위](references/time-and-scope.md)
- 새 템플릿은 시간 미정·타이머 꺼짐입니다. 현재 시간과 타이머 사용이 정해지면 설정합니다.
- 본격 제작 전 전체 페이지의 내용·배치·진행 방식·시간을 제안하고 확인받습니다. 승인된 구성 안에서는 반복 확인 없이 작업합니다.
- 대본은 발표자 노트에 두고 화면에는 핵심 메시지와 실제 장면을 크게 보여줍니다.
- 짧은 한국어 제목, 굵은 글꼴·밝은 색상·색 테두리를 사용합니다. 기관명과 로고는 기본적으로 비워 두며, 요청받은 경우에만 넣습니다.
- **캐릭터는 기본으로 넣지 않습니다.** 반디·디디는 요청할 때만 활성화합니다.
- 푸터는 페이지 이동, 내부 탭은 해당 화면의 상태 변경을 담당합니다.
- 필요한 도구가 없으면 용도를 설명하고 설치 여부를 묻습니다. 계정 가입·로그인은 별도입니다.
- 자동 검사와 실제 화면 검토를 통과한 뒤 배포하고, 공개 주소를 다시 검사합니다.

## 포함된 것

| 경로 | 내용 |
|---|---|
| `SKILL.md` | 에이전트 실행 지침 |
| `references/` | 시작 질문, 디자인·운영 기준, 설치 안내, 검증·배포 절차 |
| `assets/starter-deck/` | 편집 가능한 브랜드 템플릿과 실행 하네스 |
| `scripts/create-deck.mjs` | 기존 폴더를 덮어쓰지 않는 프로젝트 생성기 |
| `scripts/harness.test.mjs` | 격리된 환경에서 실행하는 회귀 검사 |

7개 레이아웃은 구성 예시입니다. 실제 연수를 7장으로 제한하지 않습니다. 편집·AI 수정 요청·다섯 참여 블록과 Node 참조 서버를 포함합니다. 참여 기능은 선택 사항이며 공개 서버는 별도 준비가 필요합니다. 위 공개 체험 링크에는 이번 편집·참여 기능을 아직 배포하지 않았습니다.

## 직접 실행하기

Node.js 22 이상이 있는 환경에서 저장소 루트 기준으로 실행합니다.

```sh
node scripts/create-deck.mjs --dest ../my-workshop --name my-workshop-example
cd ../my-workshop
npm run doctor
npm run check
npm run dev
```

`doctor`는 도구 상태만 확인하며 자동 설치하지 않습니다. Playwright·Chromium·Wrangler 설치는 사용자 동의 후 진행합니다. 자세한 명령과 동의 안내는 [처음 쓰는 사용자의 준비와 배포](references/setup-and-deploy.md)를 참고하세요.

배포용 Cloudflare 계정과 로그인은 사용자가 준비합니다. 기본 배포 하네스는 새 이름의 정적 발표자료를 대상으로 하며, `public/`만 업로드합니다. 실시간 서버가 필요한 경우에는 해당 프로젝트의 서버 검사와 배포 절차를 추가해야 합니다.

## 검증

스킬 자체의 회귀 검사는 아래 명령으로 실행합니다. 브라우저 관련 검사는 사용 가능한 Playwright가 있어야 실행됩니다. 누락 시 해당 검사는 생략되므로 결과의 skip 수를 확인하세요.

```sh
node --test scripts/*.test.mjs
```

브라우저와 배포 도구가 이미 제공된 환경에서는 `WORKSHOP_PLAYWRIGHT_MODULE`, `WORKSHOP_WRANGLER_CLI`로 기존 설치를 연결할 수 있습니다. [검증 절차와 범위](references/verification.md)를 참고하세요.

배포 전에는 정적 검사 → 실제 브라우저 검사 → 캡처 검토 → 배포 사전 검사 순으로 진행합니다. 실패하거나 파일이 바뀌면 이전 결과로 배포할 수 없습니다. 공개 후에는 빌드 일치와 화면·동작을 다시 확인합니다.

## 화면에서 수정하기

로컬 발표 주소 뒤에 `?edit=1`을 붙이고 ‘편집’을 누르세요. 대상을 클릭해 직접 고치거나 AI 요청을 다섯 개씩 모을 수 있습니다. 요청·편집본·소스 ZIP을 AI에게 함께 주고, 받은 데이터 변경안을 미리 본 뒤 취소/확정합니다. ChatGPT 주석을 사용할 수 없는 브라우저에서는 복사/JSON 저장을 사용합니다. 편집본과 발표용 단일 HTML을 따로 저장할 수 있습니다.

```sh
node scripts/create-deck.mjs --dest ../editor-live-demo --example editor-live
# 생성한 프로젝트에서 npm run dev → /?edit=1
# 참여 서버는 npm run live → /live-host/ → 회차 생성 → 참가자 코드/URL 공유
```

원본 전달 ZIP은 의존성 없이 생성합니다.

```sh
node scripts/package-deck.mjs --project ../editor-live-demo --dest ../demo-source.zip
```

## 브랜드와 글꼴

기존 반올림 디자인의 색감·글꼴·프레임을 유지하되, 새 발표자료에는 연구회 이름·로고를 기본으로 표시하지 않습니다. 동봉된 기존 브랜드 자료와 캐릭터는 요청받은 경우에만 선택적으로 사용합니다. Pretendard의 [동봉 라이선스](assets/starter-deck/public/assets/fonts/Pretendard-LICENSE.txt)는 유지해야 합니다.
