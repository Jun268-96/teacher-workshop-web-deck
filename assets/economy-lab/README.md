# 가계와 기업 · 서버 연결 예시

생성한 폴더에서 `npm start`로 실행한다(Node 22 이상, 추가 패키지 없음). 교사 전용 주소는 출력에만 나오며 학생에게 공유하지 않는다. 교사 키·학생 토큰·`.economy-data/`를 공개하지 않는다. 키 파일과 상태 파일은 같은 폴더에서 보존해야 재시작 시 복원된다.

- 교사는 준비 → 낮 → 밤 → 돌아보기를 진행하고 전체 현황을 본다.
- 학생 입장 시 가계/기업을 번갈아 배정한다. 여러 사람을 체험하려면 서로 다른 브라우저/프로필을 쓴다.
- 가계는 40, 기업은 120으로 시작한다. 낮에 가계가 일하면 임금 20, 재료비 10 지출과 상품 2개 생산을 함께 처리한다.
- 기업은 낮에 상품/가격을 정한다. 가계는 밤에 구매하거나 돈을 남기고 선택 이유를 적는다.
- 금액과 상품은 체험용 가정이며 성적·순위·실제 화폐가 아니다. 운영 결과에는 미판매 재고 가치를 반영하지 않는다.
- 서버가 잔액·재고·거래·역할을 계산/저장한다. 같은 요청 재전달은 한 번만 처리한다.
- 초기화 확인은 학생 역할·거래를 지우고 재입장을 요구한다. 취소하면 보존한다.

이 서버는 127.0.0.1 전용 로컬 참조 구현이다. 학생 태블릿이나 인터넷으로 공개 배포된 상태가 아니다. 운영 배포에는 인증·HTTPS·세션 분리·저장소/보존 정책·실제 기기 검증을 추가한다. 정적 HTML 업로드만으로 서버가 배포되지 않는다.

스킬 저장소의 `references/economy-lab.md`에 자료 대응표, 만드는 흐름과 검증 기준이 있다. 기존 연수의 원본 PPT/이미지/대화는 이 예시에 포함하지 않는다.
