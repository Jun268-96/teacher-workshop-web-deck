# 연수 브리프

## 확인된 조건

- 주제 / 청중의 사전 경험:
- 연수 후 이해하거나 실행할 한 가지:
- 연수 유형: 사례 소개·설명 / 따라하기 / 결과물 제작 워크숍
- 필수 확인: 실습·참여 활동 포함 여부 / 사용자 응답·해당 판단의 명시적 위임:
- 필수 확인: 반드시 포함할 내용·사례·자료·문구 / 없음·미정 여부와 사용자 응답:
- 전체 시간 / 설명·시연·참가자 실습·피드백 / Q&A·휴식 포함 여부:
- 실습 결과물·완료 기준 / 준비할 기기·계정 / 사전 설치·가입 여부:
- 장소·기기·네트워크·로그인 조건:
- 강사 / 기관 / 날짜:
- 브랜드: 기본 디자인(로고·기관명 없음) / 기존 디자인 유지 / 제공받은 기관 정보 적용
- 캐릭터: 기본 없음. 명시적으로 요청한 경우에만 사용

## 자료와 범위

- 입력 경로: 주제부터 만들기 / 기존 자료를 웹으로 만들기 / 혼합
- 기존 자료 변환 방향: 원본 흐름 유지 / 전달력 중심 재구성

- 정본으로 삼을 자료 / 필수 문구 / 제외할 내용:
- 실제 사례·원문 대화·캡처·링크와 공개 범위:
- 발표자 행동 / 그때 청중이 보고 하게 될 일:
- 참가자 화면과 실시간 기능(필요한 경우):
- 배포 요청 여부 / 대상 / 계정 연결 상태:

## 아직 모르는 것과 가정

자료와 기존 대화에서 확인된 것은 다시 묻지 않는다.
