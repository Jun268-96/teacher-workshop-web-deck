# 화면 구성안

## 확인 상태

- 상태: 제안 / 수정 중 / 사용자 확인 완료 / 사용자 명시적 생략
- 구성안 버전:
- 사용자 확인 응답과 확인한 범위:

실제 응답이 있을 때만 확인 완료로 기록한다. 새 연수·전체 재구성은 사용자에게 모든 페이지 구성을 보여주고 확인받은 뒤 본격 제작한다. 이미 승인된 안이나 작은 수정은 다시 승인받지 않는다.

|---|---|---|---|---:|---|---|

핵심·선택·생략 구간과 Q&A 포함 여부를 함께 기록한다. 제목이나 도입 장면을 의무로 추가하지 않는다.
