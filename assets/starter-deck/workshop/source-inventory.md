원자료를 곧바로 슬라이드 카피로 옮기지 않는다. 변동 가능한 사실은 공식 출처와 확인일을 남긴다.

## 기존 자료의 대응표(해당할 때)

- 정본 자료 / 원본 버전:
- 원본 흐름 유지 / 전달력 중심 재구성:
- 반드시 보존할 내용·표현 / 승인받은 제외 범위:

| 원본 파일·쪽/구간 | 핵심 내용 | 새 페이지 ID / 대본·자료 링크 | 유지·분할·통합·노트 이동·승인 생략 | 변경 이유·사용자 확인 | 대조 결과 |
|---|---|---|---|---|---|
| | | | | | |

읽을 수 없거나 확인하지 못한 구간은 미확인으로 남긴다. 원본 의미를 바꾸거나 임의의 사례로 채워 대응 완료로 표시하지 않는다.
