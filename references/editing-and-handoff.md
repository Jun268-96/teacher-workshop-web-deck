# 편집·AI 수정 요청·전달

## 적용 범위와 모드

템플릿은 기존 HTML/CSS와 동작을 보존하고 `data-edit-key`로 표시된 요소만 편집 데이터에 연결한다. 일반 주소는 발표 모드다. **`/?edit=1#페이지ID`**로 열어 ‘편집’을 누르면 선택 패널이 나타난다. 발표로 돌아가면 편집 UI를 숨긴다. 텍스트/사진/화면 블록은 클릭 또는 대상 선택 메뉴로 고른다. 페이지 선택 메뉴로 휴대폰에서도 여러 페이지를 오간다. 텍스트는 더블클릭 후 바로 고치거나 패널에서 수정한다. Tab/터치로도 패널을 사용할 수 있다.

이 기능을 추가하는 일과 연수의 사례·형식·활동을 바꾸는 일은 다르다. 강의 중심으로 승인된 연수에 투표·역할극을 임의로 추가하지 않는다. 기존에 확인한 청중·실습 여부·필수 내용을 다시 묻지 않는다.

직접 수정: 문구, 글자 스타일, 위치·크기, PNG/JPEG/WebP 추가·교체·삭제, YouTube URL, 페이지 추가·복제·삭제·순서, 발표 노트·초 단위 시간. 사진은 파일당 2MB 이하, 편집 문서는 12MB 이하다. SVG/외부 임의 이미지 URL/가져온 HTML·스크립트 실행은 지원하지 않는다. YouTube는 재생 때 온라인 연결이 필요하다.

레이아웃은 **기존 반응형 흐름+너비(%)와 제한된 상대 이동**이다. PowerPoint의 무제한 절대 배치/다중 선택/타임라인은 구현하지 않았다. 선택 요소는 드래그로 옮길 수 있고 숫자 입력도 가능하다. 이동은 정수 %, 너비는 5% 단위, 높이는 10px 단위로 조정한다. 긴 문구와 과한 이동은 다른 화면 크기에서 반드시 다시 확인한다. 의미가 바뀌거나 복잡한 동작이 필요하면 AI 요청으로 넘긴다.

## 데이터 정본

- `deck-model.js`: 스키마·값 검증. `editor.js`: 원본 페이지 템플릿과 정본 문서를 결합해 렌더링한다. 임시 DOM만 저장하는 방식이 아니다.
- 문서: schema/templateVersion/deckId/revision/pages. 페이지: id/template/title/notes/seconds/objects. 요소: id/key/type/content/style/behavior/deleted.
- 페이지 ID는 순서·제목과 독립적이다. `data-edit-key`는 페이지 템플릿 안에서 유일하고 이름이 바뀌어도 유지한다. 복제 페이지/요소는 새 UUID를 받고 원본 템플릿 참조는 유지한다. 기본 템플릿의 기존 DOM ID와 런타임 기능은 유지하며 복제본의 ID/aria 참조만 바꾼다.
- 로컬 저장은 `workshop-editor:v1:<deckId>` 키를 사용한다. 저장 실패는 화면에 표시하고 파일 저장을 안내한다. 서로 다른 프로젝트에는 서로 다른 deckId를 부여한다. 여러 탭의 동시 편집 병합은 아직 지원하지 않는다.
- 실행 취소·다시 실행은 문서 단위이며 최근 40개 변경을 유지한다(새로고침 뒤에는 이력 초기화). 요청 목록은 별도 저장한다. 현재 문서에서 삭제한 업로드 이미지는 제거되며, 실행 취소가 가능한 메모리 이력에는 일시적으로 남을 수 있다.
- 원본 템플릿 구조를 코드로 크게 변경하면 templateVersion을 올리고 마이그레이션을 제공한다. 다른 템플릿의 편집 JSON을 억지로 적용하지 않는다.

## 자유 요청과 정확한 대상

대상을 선택하고 자유롭게 적어 ‘요청 목록에 추가’를 누른다. 동작 조건(호버/클릭/값 변경/제출)은 선택 사항이다. 여러 페이지의 요청을 모아 개별 수정·삭제하고 전체 복사/JSON 저장할 수 있다. 이 정리에 AI API나 결제는 필요 없다.

맥락에는 덱·버전, 페이지 ID/제목/노트/시간, 요소 ID/유형/현재 내용·스타일·동작, 현재 탭/입력 상태, 기존 data-/aria- 동작 속성, 이미지 참조, 사용자의 요청과 영향 검토 항목을 넣는다. 입력에 개인 정보가 있을 수 있으므로 전달 전 내용을 확인한다. 업로드 사진은 요청 문맥에 데이터 전체를 반복하지 않고 `embedded:<objectId>`로 참조한다. 편집본 JSON에 실제 이미지가 들어 있다.

요청은 **수집 당시 상태**다. 그 뒤 수정했다면 context.revision과 현재 편집본을 대조한다. 삭제된 대상이나 내용 충돌을 AI가 멋대로 다른 대상으로 바꾸면 안 된다. 요청 파일만으로 새 대화가 원본에 접근할 수 없다. **요청 JSON+편집 JSON+원본 소스 ZIP**을 함께 전달한다.

## AI 변경안 검토

지원하는 로컬 변경안은 데이터만 담은 JSON이다. AI가 소스에 접근하지 못하면 필요한 파일을 요청하고 코드를 읽은 척하지 않는다.

```json
{
  "deckId": "my-workshop",
  "baseRevision": 3,
  "changes": [{
    "pageId": "message",
    "objectId": "message-heading",
    "set": {"content": "새 문구", "style": {"fontSize": 56}, "behavior": {"tooltip": "추가 설명"}}
  }],
  "pageUpdates": [{"pageId": "message", "notes": "발표자 설명", "seconds": 90}]
}
```

‘AI 변경안 불러오기’는 일치하는 덱·버전·ID/필드/값을 검사하고 **저장 전 실제 화면에 미리 보여준다**. 취소/ESC는 정본 화면으로 되돌리고, 확정은 한 번의 변경으로 저장한다. 확정 뒤 실행 취소도 가능하다. 현재 내용과 다른 과거 버전의 패치는 거절한다. 자동 병합하지 않는다.

지원 필드는 요소 content/style/behavior와 페이지 notes/seconds다. 복잡한 분기·서버·맞춤 동작은 AI가 실제 소스를 수정하고 하네스로 확인해야 한다. 이 JSON 적용기를 임의 코드 실행기로 확장하지 않는다. 동봉 동작 편집은 호버 설명과 클릭 설명이다. 값 변경/제출은 요청 조건으로 전달하며 범용 실행기를 구현했다고 소개하지 않는다.

다섯 요소 요청 → 각각의 ID를 대상으로 AI 변경 JSON 생성 → 화면 미리보기 → 취소/확정 → 실행 취소가 첫 수직 시나리오다. 테스트에서는 결정적인 변경 JSON을 사용하며 실제 유료 모델의 응답 품질을 검증한 것은 아니다.

## 공식 ChatGPT 주석과 대체 경로

[OpenAI 공식 Annotations Extensibility 문서](https://learn.chatgpt.com/docs/annotations-extensibility)를 현재 환경에서 확인한다. 현재 어댑터는 `document.oai?.annotation?.request`를 기능 탐지하고, 실제 사용자 클릭 안에서 연결된 DOM 대상을 전달한다. 각 페이지는 `oai-annotation-container`, 요소는 `oai-annotatable` 및 작은 평면 metadata를 사용한다.

metadata는 5개 속성(deckId/revision/pageId/objectId/objectType)만 사용하고 문자열은 제한 안에 둔다. 전체 요청은 자체 파일로 전달한다. `initialComment`는 240 UTF-16 단위까지다. `accepted`는 요청 수락 여부이며 실제 편집기 표시·전송·AI 코드 수정·저장·배포를 보증하지 않는다. 등록된 custom controls로 정본을 미리 덮어쓰지 않는다(이번 어댑터는 custom controls 미사용).

지원하지 않으면 주석 버튼을 숨기고 자체 요청 목록과 복사/파일 저장을 제공한다. API가 있어도 거절되거나 던진 예외는 대체 경로로 안내한다. 자동 조작 중 브라우저가 주석 요청을 거절할 수 있으므로, 실제 사용자 전송 확인 없이 ‘연동 완료/자동 수정’이라고 말하지 않는다.

## 전달과 대본·시간

- **편집 JSON**: 로컬 변경·업로드 이미지·요청·발표 노트를 포함. 같은 원본 프로젝트에서 다시 불러온다. 발표 파일과 구별한다.
- **발표용 HTML**: 현재 화면을 굳히고 CSS/JS/폰트/이미지를 내장한다. 편집 패널·요청·발표 노트를 포함하지 않는다. YouTube/외부 링크/참여 기능은 온라인 의존성을 유지한다. 내보내기는 로컬 HTTP 서버에서 한다. file://에서 fetch가 막히면 편집본을 보존하고 HTTP 실행을 안내한다.
- **원본 ZIP**: `node scripts/package-deck.mjs --project <project> --dest <new.zip> [--edit <edit.json>] [--include-notes]`. 소스·서버·하네스·에셋을 포함하고 비밀 키/의존성/실제 참여 데이터는 제외한다. 비공개 발표 노트는 명시 옵션일 때만 넣는다. 외부 전달 전 검토한다.

수정 후 화면만 확인하지 않는다. 사례의 의미, 대본·시간 배분, 앞뒤 페이지의 연결, 참여 활동 유무를 검토한다. 에디터의 노트는 편집본 안에 저장되며 `workshop/speaker-notes.md`를 자동 덮어쓰지 않는다. AI가 최종 소스에 반영할 때 대응표와 발표 노트를 동기화한다. 시간 합계가 확인된 총 시간에서 벗어나면 재조정하되 연수 형식을 임의로 바꾸지 않는다.
