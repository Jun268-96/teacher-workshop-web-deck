# 편집·AI 수정 요청·전달

## 적용 범위와 모드

템플릿은 기존 HTML/CSS와 동작을 보존하고 `data-edit-key`로 표시된 요소만 편집 데이터에 연결한다. 일반 주소는 발표 모드다. **`/?edit=1#페이지ID`**로 열어 ‘편집’을 누른다. 기본 UI는 [editor-workspace.md](editor-workspace.md)의 상단 도구·왼쪽 썸네일·선택 도구막대다. 긴 토글 목록은 기본으로 보여주지 않는다. 텍스트는 더블클릭으로 고치고, 사진/장면은 클릭한 뒤 가까운 도구막대에서 수정한다. 하단 `요소 선택`과 키보드·터치를 위한 기존 선택 메뉴도 유지한다. 페이지 이름·노트·시간은 페이지 노트 창, 정밀 배치는 네 가지 크기·좌표만 담은 배치 창, 마우스를 올리거나 클릭했을 때의 동작은 선택 도구막대의 별도 동작 창, 전달 기능은 `파일`에서 연다.

이 기능을 추가하는 일과 연수의 사례·형식·활동을 바꾸는 일은 다르다. 강의 중심으로 승인된 연수에 투표·역할극을 임의로 추가하지 않는다. 기존에 확인한 청중·실습 여부·필수 내용을 다시 묻지 않는다.

직접 수정은 텍스트 더블클릭, 글자 스타일 툴바(즉시 반영), 위치·크기 드래그, 정밀 배치 창(영역 대비 너비, 자동/직접 지정 높이, 원래 위치 기준 가로/세로 이동 후 배치 적용), PNG/JPEG/WebP 추가·교체·삭제, YouTube URL(영상 도구막대의 주소 변경), 페이지 추가·복제·삭제·순서, 발표 노트·초 단위 시간. 사진은 파일당 2MB 이하, 편집 문서는 12MB 이하다. SVG/외부 임의 이미지 URL/가져온 HTML·스크립트 실행은 지원하지 않는다. YouTube는 재생 때 온라인 연결이 필요하다.

레이아웃은 **기존 반응형 흐름+너비(%)와 슬라이드 안의 자유 이동**이다. 첫 드래그에서 대상을 선택하고 포인터 이동 거리만큼 옮긴다. 요소끼리 겹쳐 놓을 수 있으며, 슬라이드 가장자리에서만 제한한다. 패널에서는 이동 거리를 px로 입력한다. 저장은 슬라이드 크기에 대한 비율(`offsetX/offsetY`)로 하고 화면 크기가 달라지면 다시 배치한다. 기존 `x/y` 편집본도 읽으며, 새로 이동하면 새 좌표로 변환한다. 기본 너비가 늘어난 텍스트는 첫 이동 때 글자 크기에 맞춰 박스 너비를 줄이고, 사용자가 지정한 너비는 보존한다. 패널 너비는 1~100% 범위의 1% 단위, 높이는 10px 단위다. 긴 문구와 과한 이동은 다른 화면 크기에서 반드시 다시 확인한다. PowerPoint의 무한 캔버스/다중 선택/타임라인은 구현하지 않았다.

정밀 배치의 높이는 ‘내용에 맞춤 (자동)’ 또는 ‘직접 지정’이다. 자동에서는 px 입력칸을 숨기고 비활성화하며, 직접 지정에서는 현재 박스 높이를 초기값으로 보여주고 1~800px의 최종 높이를 입력한다. 모드 선택만으로 저장하지 않고 ‘배치 적용’ 때 반영한다. 자동은 기존 데이터의 height:0(또는 생략)과 호환하고, 양수 px 높이는 직접 지정으로 복원한다. 글자 크기·내용·동작을 바꾸지 않는다. 기존 요소의 이동 0은 원래 자동 배치 위치이고 +가로는 오른쪽, +세로는 아래쪽이다.

텍스트/사진을 선택하면 네 모서리에 **크기 조절 핸들**이 나타난다. 마우스나 터치로 끌면 반대 모서리를 고정한 채 비례 확대·축소하고, 놓을 때 한 번의 변경으로 저장한다. 사진 박스는 현재 가로세로 비율을 유지하며 이미지 자체는 `contain`으로 왜곡을 막는다. **텍스트는 박스와 글자 크기를 같은 비율로 바꾼다.** 폰트는 12~140px 범위이며 슬라이드 경계에서 확대를 제한한다. 박스 너비·높이만 따로 바꾸려면 패널의 숫자 입력을 쓴다. Escape 또는 터치 취소는 조절 중인 변경을 버린다. 실행 취소/다시 실행과 편집본 복원을 지원하며, 동작 시험/발표/내보낸 HTML에는 핸들이 나타나지 않는다.

이동 중 **페이지 가로·세로 중앙과 같은 페이지의 다른 요소 박스 가장자리·중앙**에 가까워지면 분홍 가이드선과 자동 맞춤을 제공한다. 숨겨진 요소와 이동 대상의 부모/자식은 기준에서 제외한다. 마우스는 6px, 터치는 10px 안에서 가장 가까운 기준을 고른다. Alt를 누르면 가이드/자동 맞춤을 잠시 끄고 자유롭게 움직인다. 놓거나 터치를 취소하면 선은 사라지고, 놓은 위치만 저장한다. 요소 간 겹침 방지는 아니다. 발표용 HTML에는 가이드 UI를 포함하지 않는다.

`동작 설정`에서는 마우스를 올려놓았을 때의 말풍선과 클릭/터치 시 할 일을 별도로 고른다. 클릭은 설명 창 열기/사진 바꾸기/다른 요소 보이기·숨기기/아무 일도 하지 않기다. 설명·대상·바뀔 사진 중 선택한 동작에 필요한 입력만 보여준다. 대상은 `화면에서 대상 고르기`로 같은 페이지의 글자·사진을 직접 클릭한다. 선택하는 동안 설정 창/편집 툴바/크기 조절 손잡이는 비켜나며, 해당 클릭은 선택만 하고 요소 이동이나 실제 발표 동작을 실행하지 않는다. 방향키/Tab은 후보 강조·이동, Enter/Space는 선택, Esc/취소는 원래 대상과 설명·업로드 사진 초안을 유지한다. 페이지를 바꾸면 선택 모드를 끝내고 적용하지 않는다. 클릭할 요소와 대상은 색 테두리/연결선, 선택 뒤 문구·사진 미리보기로 확인한다. 연결선/대상 이름표를 누르면 해당 동작 설정을 바로 연다. 닫아 둔 창에서 저장된 선을 다시 열 때는 그 선의 저장값을 보여주며, 설정 창에서 연결을 고르는 중인 선은 현재 초안을 유지한다. ‘연결 끊기’는 별도 적용 없이 클릭 연결만 해제하고 대상 요소·내용·스타일·마우스 안내를 남긴다. 다른 입력 초안도 유지하며 실행 취소/다시 실행·저장/복원을 지원한다. 적용 전 연결 선택을 끊는 것은 정본이나 이력을 바꾸지 않는다. 적용 뒤에는 요소를 선택할 때 저장된 관계를 다시 보여주고, 미리보기/발표/HTML에서는 편집 표시를 제거한다. 사진 교체는 PNG/JPEG/WebP(2MB 이하)를 올리며 두 번째 클릭으로 원본에 돌아온다. 보이기 대상은 발표 시작에 숨기고 클릭마다 나타났다 사라진다. 숨길 때 자리 크기를 유지해 주변 배치가 움직이지 않으며 편집 중에는 흐리게 보여 선택·수정할 수 있다. 자신이나 클릭 대상을 감추는 부모/자식은 보이기 대상으로 고르지 않는다.

‘적용하고 미리보기’를 누르면 **동작 시험**으로 전환된다. 대상/사진 선택만으로 저장하지 않으며, 빠진 입력은 설정 창 안에서 안내한다. 미리보기 시작/종료, 페이지 재진입, 발표 HTML 열기는 처음 상태로 돌아간다. 클릭 후 바뀐 사진/표시 상태는 정본 변경이 아니며 저장/내보내기에 섞이지 않는다. 키보드 Enter/Space와 터치를 지원한다. ‘편집으로’ 또는 Escape로 돌아오면 드래그/선택을 다시 사용할 수 있다. 편집 모드의 클릭은 선택을 위해 실제 동작을 막는다. 발표 모드와 발표용 HTML에서는 별도 시험 전환 없이 동작한다.

## 데이터 정본

- `deck-model.js`: 스키마·값 검증. `editor.js`: 원본 페이지 템플릿과 정본 문서를 결합해 렌더링한다. 임시 DOM만 저장하는 방식이 아니다.
- 문서: schema/templateVersion/deckId/revision/pages. 페이지: id/template/title/notes/seconds/objects. 요소: id/key/type/content/style/behavior/deleted. 장면은 추가 유형 `scene`으로 저장하며 content의 JSON을 `scene-runtime.js`가 엄격히 검증한다. 기존 편집본과 저장 키는 유지한다.
- 페이지 ID는 순서·제목과 독립적이다. `data-edit-key`는 페이지 템플릿 안에서 유일하고 이름이 바뀌어도 유지한다. 복제 페이지/요소는 새 UUID를 받고 원본 템플릿 참조는 유지한다. 기본 템플릿의 기존 DOM ID와 런타임 기능은 유지하며 복제본의 ID/aria 참조만 바꾼다.
- 로컬 저장은 `workshop-editor:v1:<deckId>` 키를 사용한다. 저장 실패는 화면에 표시하고 파일 저장을 안내한다. 서로 다른 프로젝트에는 서로 다른 deckId를 부여한다. 여러 탭의 동시 편집 병합은 아직 지원하지 않는다.
- 실행 취소·다시 실행은 문서 단위이며 최근 40개 변경을 유지한다(새로고침 뒤에는 이력 초기화). 요청 목록은 별도 저장한다. 현재 문서에서 삭제한 업로드 이미지는 제거되며, 실행 취소가 가능한 메모리 이력에는 일시적으로 남을 수 있다.
- 원본 템플릿 구조를 코드로 크게 변경하면 templateVersion을 올리고 마이그레이션을 제공한다. 다른 템플릿의 편집 JSON을 억지로 적용하지 않는다.

## 자유 요청과 정확한 대상

대상을 선택하고 자유롭게 적어 ‘요청 목록에 추가’를 누른다. 동작 조건(호버/클릭/값 변경/제출)은 선택 사항이다. 여러 페이지의 요청을 모아 개별 수정·삭제하고 전체 복사/JSON 저장할 수 있다. 이 정리에 AI API나 결제는 필요 없다.

맥락에는 덱·버전, 페이지 ID/제목/노트/시간, 요소 ID/유형/현재 내용·스타일·동작, 현재 탭/입력 상태, 기존 data-/aria- 동작 속성, 이미지 참조, 사용자의 요청과 영향 검토 항목을 넣는다. 입력에 개인 정보가 있을 수 있으므로 전달 전 내용을 확인한다. 업로드 사진은 요청 문맥에 데이터 전체를 반복하지 않고 `embedded:<objectId>`로 참조한다. 교체 동작의 업로드 사진도 `embedded-action:<objectId>`로 참조하고 정본의 `behavior.click.src`에 원본을 유지한다. 편집본 JSON과 요청함의 현재 편집본에는 실제 이미지가 들어 있다.

요청은 **수집 당시 상태**다. 그 뒤 수정했다면 context.revision과 현재 편집본을 대조한다. 삭제된 대상이나 내용 충돌을 AI가 멋대로 다른 대상으로 바꾸면 안 된다. 요청 파일만으로 새 대화가 원본에 접근할 수 없다. 프로젝트 폴더를 공유하는 에이전트에는 [로컬 요청함](local-editor-inbox.md)이 현재 편집본과 요청을 함께 전달하므로 복사/첨부가 필요 없다. 파일 접근이 없는 새 환경에 수동으로 전달할 때는 **요청 JSON+편집 JSON+원본 소스 ZIP**을 함께 전달한다.

## AI 변경안 검토

지원하는 로컬 변경안은 데이터만 담은 JSON이다. AI가 소스에 접근하지 못하면 필요한 파일을 요청하고 코드를 읽은 척하지 않는다.

```json
{
  "deckId": "my-workshop",
  "baseRevision": 3,
  "changes": [{
    "pageId": "message",
    "objectId": "message-heading",
    "set": {"content": "새 문구", "style": {"fontSize": 56}, "behavior": {"tooltip": "추가 설명"}}
  }],
  "pageUpdates": [{"pageId": "message", "notes": "발표자 설명", "seconds": 90}]
}
```

‘AI 변경안 불러오기’는 일치하는 덱·버전·ID/필드/값을 검사하고 **저장 전 실제 화면에 미리 보여준다**. 취소/ESC는 정본 화면으로 되돌리고, 확정은 한 번의 변경으로 저장한다. 확정 뒤 실행 취소도 가능하다. 현재 내용과 다른 과거 버전의 패치는 거절한다. 자동 병합하지 않는다.

지원 필드는 요소 content/style/behavior와 페이지 notes/seconds다. 복잡한 분기·서버·맞춤 동작은 AI가 실제 소스를 수정하고 하네스로 확인해야 한다. 이 JSON 적용기를 임의 코드 실행기로 확장하지 않는다. 동봉 대상별 동작 편집은 말풍선, 설명 창, 사진 교체, 요소 보이기·숨기기다. 기존 `behavior.tooltip`/`explain`은 유지하며 새 클릭 동작은 `behavior.click`에 `{kind:"swap-image",targetId:"사진 ID",src:"안전한 이미지"}` 또는 `{kind:"toggle",targetId:"요소 ID"}`로 저장한다. `click:null`은 AI 패치에서 클릭 동작을 지울 때 사용한다. 설명 창과 새 클릭 동작은 동시에 지정하지 않는다. 같은 페이지의 존재하는 대상·사진 유형·순환 참조·이미지 경로를 검증하고 임의 CSS/함수/스크립트는 거절한다. 페이지 복제는 대상 ID를 함께 바꾸고, 사진 자체 교체 동작의 요소 복제도 새 사진을 가리킨다. 대상 삭제 시 관련 동작을 지우며 실행 취소로 복원한다. 발표 HTML은 교체용 사진까지 내장한다. 별도의 장면 삽입은 네 가지 신뢰된 로컬 컴포넌트만 지원한다. 값 변경/제출은 요청 조건으로 전달하며 범용 실행기를 구현했다고 소개하지 않는다.

다섯 요소 요청 → 각각의 ID를 대상으로 AI 변경 JSON 생성 → 화면 미리보기 → 취소/확정 → 실행 취소가 첫 수직 시나리오다. 테스트에서는 결정적인 변경 JSON을 사용하며 실제 유료 모델의 응답 품질을 검증한 것은 아니다.

## 공식 ChatGPT 주석과 대체 경로

[OpenAI 공식 Annotations Extensibility 문서](https://learn.chatgpt.com/docs/annotations-extensibility)를 현재 환경에서 확인한다. 현재 어댑터는 `document.oai?.annotation?.request`를 기능 탐지하고, 실제 사용자 클릭 안에서 연결된 DOM 대상을 전달한다. 각 페이지는 `oai-annotation-container`, 요소는 `oai-annotatable` 및 작은 평면 metadata를 사용한다.

단일 요소 metadata는 5개 속성(deckId/revision/pageId/objectId/objectType)만 사용하고 문자열은 제한 안에 둔다. `initialComment`는 240 UTF-16 단위까지이므로 전체 요청의 운반 수단으로 쓰지 않는다. 상단 수정 요청 목록의 **모두 ChatGPT 주석으로 보내기**는 현재 목록과 대상 문맥을 읽기 전용 전달 창에 고정하고, 실제 사용자 클릭에서 그 본문을 DOM Range로 선택해 한 번에 주석을 요청한다. Range 요청에는 metadata를 넣지 않고 본문에 덱/버전/페이지/요소 ID를 포함한다. 내장 이미지 바이너리는 참조로 대체한다. 20,000 UTF-16 단위 한계보다 작게 명시적으로 분할하고, 여러 묶음이면 사용자가 각 묶음을 보낸 뒤 합쳐 검토하도록 안내한다. 자동 축약/잘라내기나 숨긴 DOM 전달은 하지 않는다. 목록은 수락/거절/취소와 무관하게 보존하며 수락을 전송 완료로 표시하지 않는다. `accepted`는 요청 수락 여부이며 실제 편집기 표시·전송·AI 코드 수정·저장·배포를 보증하지 않는다. 등록된 custom controls로 정본을 미리 덮어쓰지 않는다(이번 어댑터는 custom controls 미사용).

localhost는 지원 환경에 포함되지만, 이 API는 ChatGPT 데스크톱 앱의 지원되는 내장 브라우저에 의존한다. 일반 브라우저나 Claude용 공통 전송 API가 아니다. 지원하지 않으면 주석 버튼을 숨기고 이유를 표시하며 같은 프로젝트의 로컬 요청함을 우선 제공하고, 로컬 연결도 없으면 복사/파일 저장을 제공한다. Claude Code와 같이 프로젝트 파일을 읽는 환경에는 `npm run dev`의 디스크 요청함과 CLI, 결과 변경안 확인 경로를 사용한다. Claude 웹에 localhost 주소를 주는 것만으로 요청이나 소스가 전달된다고 설명하지 않는다. API가 있어도 거절되거나 던진 예외는 대체 경로로 안내한다. 자동 조작 중 브라우저가 주석 요청을 거절할 수 있으므로, 실제 사용자 전송 확인 없이 ‘연동 완료/자동 수정’이라고 말하지 않는다.

## 전달과 대본·시간

- **편집 JSON**: 로컬 변경·업로드 이미지·요청·발표 노트를 포함. 같은 원본 프로젝트에서 다시 불러온다. 발표 파일과 구별한다.
- **발표용 HTML**: 현재 화면을 굳히고 CSS/JS/폰트/이미지를 내장한다. 편집 패널·요청·발표 노트를 포함하지 않는다. YouTube/외부 링크/참여 기능은 온라인 의존성을 유지한다. 내보내기는 로컬 HTTP 서버에서 한다. file://에서 fetch가 막히면 편집본을 보존하고 HTTP 실행을 안내한다.
- **원본 ZIP**: `node scripts/package-deck.mjs --project <project> --dest <new.zip> [--edit <edit.json>] [--include-notes]`. 소스·서버·하네스·에셋을 포함하고 비밀 키/의존성/실제 참여 데이터는 제외한다. 비공개 발표 노트는 명시 옵션일 때만 넣는다. 외부 전달 전 검토한다.

수정 후 화면만 확인하지 않는다. 사례의 의미, 대본·시간 배분, 앞뒤 페이지의 연결, 참여 활동 유무를 검토한다. 에디터의 노트는 편집본 안에 저장되며 `workshop/speaker-notes.md`를 자동 덮어쓰지 않는다. AI가 최종 소스에 반영할 때 대응표와 발표 노트를 동기화한다. 시간 합계가 확인된 총 시간에서 벗어나면 재조정하되 연수 형식을 임의로 바꾸지 않는다.

## 직접 추가와 자유 위치 데이터

상단 텍스트·사진·동영상, 클립보드 붙여넣기와 외부 드롭으로 추가한 요소는 `style.position: "absolute"`를 사용한다. 이 한 값만 검증하며 임의 CSS position은 허용하지 않는다. 부모 페이지의 왼쪽 위를 원점으로 기존 `offsetX/offsetY` 비율과 너비(%), 높이(px)를 저장한다. 기존 흐름 요소/좌표/스키마 1/저장 키는 자동 변환하지 않는다. 이동·크기 조절·정밀 배치·가이드·복제·JSON·요청함·오프라인 HTML은 같은 정본을 사용한다. 새 데이터를 읽는 쪽도 현재 모델 파일을 사용해야 한다.

미리보기/대상 선택/설정 창 안에서는 외부 드롭으로 정본을 바꾸지 않는다. 입력칸과 contenteditable의 붙여넣기는 가로채지 않는다. 사진 읽기 후 현재 페이지와 revision을 다시 확인하고 변경됐으면 취소한다. URL을 임의로 가져오거나 가져온 HTML을 실행하지 않으며, YouTube만 정규화해 iframe으로 저장한다. 사진 교체와 새 요소 추가는 분리한다. 요청함 검증 VM에도 표준 URL 파서를 제공해 YouTube를 브라우저와 동일하게 검증한다.
