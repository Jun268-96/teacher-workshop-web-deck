# 직관적인 기본 편집 화면

완성된 발표자료에서 대상을 직접 고치는 화면이다. 사용자가 승인한 Pitch/Canva식 조작 방향을 따른다. 실제 연수자료를 새 템플릿으로 자동 덮어쓰지 않는다.

## 평소 보이는 것

상단에는 저장 상태·실행 취소/다시 실행·추가·파일·미리보기, 왼쪽에는 페이지 썸네일, 가운데에는 큰 발표 화면을 둔다. 아무것도 선택하지 않으면 속성 패널을 숨긴다. 선택한 요소 가까이에 필요한 도구만 표시한다. 기본 조작을 아코디언 목록이나 긴 설정 폼으로 시작하지 않는다.

- **텍스트**: 더블클릭으로 바로 입력. 작은 도구막대에서 크기·굵기·색·정렬을 즉시 반영한다.
- **사진**: 교체/자르기와 모서리 크기 조절. 자르기는 확인 후 PNG 결과로 반영하며 실행 취소로 원본에 돌아간다. 다시 자르기는 현재 사진을 기준으로 한다.
- **정밀 배치**: 선택 도구막대의 배치 버튼으로 기존 너비·높이·이동 거리·내용 입력을 연다. 기본 직접 조작을 숫자 입력으로 대체하지 않는다.
- **페이지**: 썸네일로 이동/끌어 순서 변경. 페이지 노트 버튼으로 이름·노트·예상 시간·추가/복제/삭제/이동을 연다. 시간 미정은 타이머 활성화의 근거가 아니다.
- **겹친 요소**: 하단 `요소 선택`에서 정확한 대상 ID를 선택한다.
- **동작**: 정밀 배치 창의 `동작 설정` 또는 블록 도구막대에서 기존 호버/클릭 설명을 편집한다. 적용 후 미리보기로 시험하며 편집으로 돌아올 수 있다.
- **요청**: 대상의 `수정 요청`에서 자유 입력/조건/공식 주석을 사용하고, 상단 요청 목록에서 개별 수정·삭제하고 **모두 ChatGPT 주석으로 보내기**로 한 번에 전달 창을 연다. 마지막 전송은 사용자가 주석 창에서 확인한다. **프로젝트 요청함에 저장**은 현재 편집본과 요청을 같은 프로젝트 폴더에 보관한다. 에이전트가 변경안을 등록하면 **변경안 확인**에서 파일 선택 없이 미리보고 확정한다. [로컬 요청함](local-editor-inbox.md)을 참조한다. 복사·JSON 저장은 주석과 로컬 요청함 모두 없는 환경의 대체 경로로 남긴다.
- **파일**: 편집 JSON 불러오기/저장, 에셋 내장 발표 HTML, AI 변경안 불러오기, 편집 끝내기를 제공한다. 노트·요청·편집 UI는 발표용 HTML에서 제거한다.

선택 도구막대가 화면 밖으로 나가지 않게 하고, 작은 화면에서는 줄바꿈한다. 긴 설정/삽입 내용은 내부 스크롤하며 닫기와 주요 동작 버튼을 확인한다. 썸네일은 실제 런타임과 분리된 inert 미리보기다. 입력·미디어·탭의 중복 실행 대상이 되지 않는다.

## 장면 삽입

`추가`에서 텍스트·사진·YouTube와 네 가지 신뢰된 로컬 장면(클릭 공개, 사진 비교, 숫자 모션, 사진 슬라이드)을 넣는다. 장면을 먼저 실제로 시험한 뒤 현재 페이지/새 페이지를 선택한다. 장면 내용은 선택 도구막대에서 수정한다. 비교/슬라이드에는 업로드한 사진 두 장을 설정할 수 있다.

장면은 `type:scene`과 검증된 JSON 설정으로 저장하며 `scene-runtime.js`만 실행한다. 임의 HTML·함수·외부 스크립트는 설정에 넣지 않는다. 기존 schema 1 텍스트/사진/블록 편집본과 저장 키는 유지한다. 장면을 포함한 새 편집본은 장면 런타임이 포함된 현재 소스와 함께 전달한다.

## 웹과 백엔드

편집 UI의 단순화는 서버 기능을 제거하는 일이 아니다. 설문/제출/집계/권한/재접속은 기존 참여 서버와 클라이언트가 맡으며 편집 정본과 구분한다. 이 네 가지 삽입 장면은 해당 기기에서 실행되는 로컬 기능이다. 여러 기기의 실시간 참여는 승인된 구성에서 선택형 참여 모듈과 실제 서버를 연결하고 다중 브라우저로 검사한다. 정적 발표 HTML만 내보내서 서버까지 배포됐다고 말하지 않는다.

기본 편집기 변경 시 브라우저 저장·과거 편집본 가져오기·드래그/리사이즈/가이드·페이지 복제·요청 문맥·AI 변경안 취소/확정·발표 HTML·참여 서버 경로를 함께 회귀 검사한다. 서로 다른 탭의 동시 수정 병합은 이번 편집기에도 포함하지 않는다.
