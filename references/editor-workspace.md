# 직관적인 기본 편집 화면

완성된 발표자료에서 대상을 직접 고치는 화면이다. 사용자가 승인한 Pitch/Canva식 조작 방향을 따른다. 실제 연수자료를 새 템플릿으로 자동 덮어쓰지 않는다.

## 평소 보이는 것

상단에는 저장 상태·실행 취소/다시 실행·텍스트·사진·동영상·장면·파일·미리보기, 왼쪽에는 페이지 썸네일, 가운데에는 큰 발표 화면을 둔다. 아무것도 선택하지 않으면 속성 패널을 숨긴다. 선택한 요소 가까이에 필요한 도구만 표시한다. 기본 조작을 아코디언 목록이나 긴 설정 폼으로 시작하지 않는다.

- **텍스트**: 더블클릭으로 바로 입력. 작은 도구막대에서 크기·굵기(보통/중간/굵게)·색·정렬을 즉시 반영한다. 같은 입력칸을 모달에 반복하지 않는다.
- **사진**: 교체/자르기와 모서리 크기 조절. 자르기는 확인 후 PNG 결과로 반영하며 실행 취소로 원본에 돌아간다. 다시 자르기는 현재 사진을 기준으로 한다.
- **정밀 배치**: 선택 도구막대의 배치 버튼으로 너비·높이·가로/세로 이동을 연다. 너비는 요소가 놓인 영역 대비 %이고, 기존 요소의 이동은 원래 자동 배치된 위치를 0으로 하는 px 차이다. 화면에서 자유롭게 추가한 요소는 페이지 왼쪽 위를 0, 0으로 삼는다. 가로 −/＋는 왼쪽/오른쪽, 세로 −/＋는 위쪽/아래쪽으로 바로 표시한다. 높이는 ‘내용에 맞춤 (자동)’과 ‘직접 지정’을 고르며, 직접 지정할 때만 최종 박스 높이(px)를 입력한다. 이 값은 증감량이나 글자 크기가 아니다. ‘배치 적용’은 이 네 값만 바꾸며 문구·글자 스타일·동작은 보존한다. 텍스트는 더블클릭하고, 영상 주소는 영상 도구막대의 ‘주소 변경’을 쓴다. 기본 직접 조작을 숫자 입력으로 대체하지 않는다.
- **페이지**: 썸네일로 이동/끌어 순서 변경. 페이지 노트 버튼으로 이름·노트·예상 시간·추가/복제/삭제/이동을 연다. 시간 미정은 타이머 활성화의 근거가 아니다.
- **겹친 요소**: 하단 `요소 선택`에서 정확한 대상 ID를 선택한다.
- **동작**: 선택 도구막대의 `동작 설정`에서 마우스를 올릴 때의 작은 말풍선과 클릭/터치 시 할 일을 고른다. 클릭은 설명 창 열기/사진 바꾸기/다른 요소 보이기·숨기기/아무 일도 하지 않기이며, 해당 설정만 보여준다. `화면에서 대상 고르기`를 누르면 설정 창이 잠시 비켜나고 같은 페이지의 사진·글자를 직접 클릭한다. 선택 가능한 대상을 강조하고 클릭할 요소와 연결 대상을 테두리/연결선으로 구분한다. 선택 뒤 설정 창의 문구/사진 미리보기로 확인하고, 사진 교체는 새 사진을 업로드한다. 방향키/Tab으로 겹친 대상을 옮겨 Enter로 고를 수 있고 Esc/취소는 이전 연결과 입력 초안을 보존한다. 연결선과 대상 이름표를 클릭하면 그 관계의 동작 설정을 연다. 이름표는 키보드/터치로도 열며 자기 사진을 바꾸는 동작에도 제공한다. ‘연결 끊기’는 저장된 클릭 연결만 즉시 해제하고 사진/글자/마우스 안내는 보존하며 실행 취소로 복원한다. 아직 적용하지 않은 선택은 초안만 취소한다. 연결선은 선택한 요소의 저장된 관계를 표시하며, 미리보기/발표/HTML 내보내기에는 넣지 않는다. 다시 클릭하면 원래 사진으로 돌아온다. 보이기 대상은 발표 시작 시 숨기고 클릭할 때마다 표시를 전환하며 자리 크기는 유지한다. 편집 중에는 흐리게 보여 계속 수정할 수 있다. `적용하고 미리보기` 전에 정본을 바꾸지 않고, 빈 대상/누락된 사진은 창 안에서 안내한다. 사용자 화면에는 ‘호버’ 같은 개발 용어 대신 행동과 결과를 적는다.
- **요청**: 대상의 `수정 요청`에서 자유 입력/조건/공식 주석을 사용하고, 상단 요청 목록에서 개별 수정·삭제하고 **모두 ChatGPT 주석으로 보내기**로 한 번에 전달 창을 연다. 마지막 전송은 사용자가 주석 창에서 확인한다. **프로젝트 요청함에 저장**은 현재 편집본과 요청을 같은 프로젝트 폴더에 보관한다. 에이전트가 변경안을 등록하면 **변경안 확인**에서 파일 선택 없이 미리보고 확정한다. [로컬 요청함](local-editor-inbox.md)을 참조한다. 복사·JSON 저장은 주석과 로컬 요청함 모두 없는 환경의 대체 경로로 남긴다.
- **파일**: 편집 JSON 불러오기/저장, 에셋 내장 발표 HTML, AI 변경안 불러오기, 편집 끝내기를 제공한다. 노트·요청·편집 UI는 발표용 HTML에서 제거한다.

선택 도구막대가 화면 밖으로 나가지 않게 하고, 작은 화면에서는 줄바꿈한다. 긴 설정/삽입 내용은 내부 스크롤하며 닫기와 주요 동작 버튼을 확인한다. 썸네일은 실제 런타임과 분리된 inert 미리보기다. 입력·미디어·탭의 중복 실행 대상이 되지 않는다.

## 텍스트·사진·동영상 바로 추가

- **텍스트**를 누르고 원하는 곳을 클릭하면 바로 글자를 입력한다. 드래그하면 박스 크기까지 정한다.
- **사진**은 파일 선택 후 위치 미리보기를 띄운다. 원하는 곳을 클릭하거나 드래그해 놓는다. PNG/JPEG/WebP, 한 번에 한 장, 파일당 2MB 이하다.
- **동영상**은 YouTube 주소를 입력하고 위치를 선택한다. MP4 파일 업로드는 아직 지원하지 않는다.
- 캔버스에서 **붙여넣기**하면 일반 문구·클립보드 사진/스크린샷·YouTube 링크를 새 요소로 넣는다. 마지막으로 가리킨 페이지 위치를 사용하고, 없으면 보이는 영역의 가운데에 놓는다. 문구 편집 중이거나 입력칸에 커서가 있으면 그 안에 원래대로 붙여넣는다.
- 사진 파일·문구·YouTube 링크를 **드래그앤드롭**하면 놓은 좌표에 새 요소를 추가한다. 기존 사진 위에 놓아도 교체하지 않는다. 교체는 해당 사진 도구막대를 쓴다.
- 위치 선택 중 Enter는 가운데/미리보기 위치에 놓기, Esc/취소는 변경 없이 닫기다. 페이지를 바꾸면 취소한다. 사진을 읽는 동안 페이지/편집 버전이 바뀌어도 다른 페이지에 추가하지 않는다.

새 요소는 기존 자동 배치를 밀어내지 않고 자유 위치에 놓인다. 이동·모서리 크기 조절·정렬 가이드·동작 연결·실행 취소·저장·발표 HTML에 이어진다. 작은 화면에서는 상단 추가 버튼을 두 번째 줄에 유지한다. 텍스트가 길거나 화면 비율이 크게 달라지면 발표 화면에서도 배치를 확인한다.

## 장면 삽입

`장면`에서 기존 텍스트·사진·YouTube 추가 경로와 네 가지 신뢰된 로컬 장면(클릭 공개, 사진 비교, 숫자 모션, 사진 슬라이드)을 넣는다. 장면을 먼저 실제로 시험한 뒤 현재 페이지/새 페이지를 선택한다. 장면 내용은 선택 도구막대에서 수정한다. 비교/슬라이드에는 업로드한 사진 두 장을 설정할 수 있다.

장면은 `type:scene`과 검증된 JSON 설정으로 저장하며 `scene-runtime.js`만 실행한다. 임의 HTML·함수·외부 스크립트는 설정에 넣지 않는다. 기존 schema 1 텍스트/사진/블록 편집본과 저장 키는 유지한다. 장면을 포함한 새 편집본은 장면 런타임이 포함된 현재 소스와 함께 전달한다.

## 웹과 백엔드

편집 UI의 단순화는 서버 기능을 제거하는 일이 아니다. 설문/제출/집계/권한/재접속은 기존 참여 서버와 클라이언트가 맡으며 편집 정본과 구분한다. 이 네 가지 삽입 장면은 해당 기기에서 실행되는 로컬 기능이다. 여러 기기의 실시간 참여는 승인된 구성에서 선택형 참여 모듈과 실제 서버를 연결하고 다중 브라우저로 검사한다. 정적 발표 HTML만 내보내서 서버까지 배포됐다고 말하지 않는다.

기본 편집기 변경 시 브라우저 저장·과거 편집본 가져오기·드래그/리사이즈/가이드·페이지 복제·요청 문맥·AI 변경안 취소/확정·발표 HTML·참여 서버 경로를 함께 회귀 검사한다. 서로 다른 탭의 동시 수정 병합은 이번 편집기에도 포함하지 않는다.
