# 기존 연수자료를 웹 발표자료로 만들기

## 시작과 변환 방향

PPT/PDF·대본·문서·기존 연수 사이트가 입력이면, 먼저 실제 내용을 읽는다. 이번 작업에서 이미 확인된 청중·시간·실습 여부는 다시 묻지 않는다. 원본의 시간표·타이머나 이전 회차의 대화는 현재 시간 조건으로 자동 승계하지 않고 [time-and-scope.md](time-and-scope.md)에 따라 구분한다. 원본의 학습 목표, 설명 순서, 사례, 실습, 발표자 노트, 필수 문구를 파악하고 여러 자료가 충돌하면 정본을 확인한다.

사용자가 정하지 않은 경우에만 다음 방향을 확인한다.

- **원본 흐름 유지**: 핵심 내용과 설명 순서를 보존하고 화면의 밀도·배치·조작을 개선한다. 긴 장은 분할하고 부연은 발표자 노트로 옮길 수 있지만 의미나 전체 흐름을 임의로 바꾸지 않는다.
- **전달력 중심 재구성**: 청중과 시간에 맞춰 순서·통합·분할·실습 배치를 제안한다. 중요한 변경·생략은 구성안에 표시하고 확인받는다.

기본 제안은 내용·의도 보존이다. 이미 재구성을 요청했다면 같은 선택을 다시 묻지 않는다. 원본이 짧다고 무관한 내용으로 채우지 않고, 오래됐다고 전체를 새 조사 내용으로 바꾸지 않는다.

## 원본 읽기

현재 환경에서 파일을 실제로 읽고 필요한 화면을 렌더링할 도구를 먼저 확인한다. 적합한 문서/프레젠테이션/PDF 도구나 스킬이 있으면 사용하되 특정 제품을 반드시 설치했다고 가정하지 않는다.

| 입력 | 확인할 내용 |
|---|---|
| PPT/PPTX | 슬라이드 순서·본문·발표자 노트·그림/도표·링크·단계적 공개 의도. 텍스트 추출과 필요한 화면 확인을 함께 사용 |
| PDF | 페이지 순서·본문·표/도형·작은 주석·출처. 스캔본은 필요 범위의 OCR과 원본 화면을 대조 |
| 대본·문서 | 청중에게 보일 메시지와 발표자 설명·운영 메모·실습 절차를 구분 |
| 기존 사이트 | 실제 페이지 본문·연결 자료·탭/단계 등 상호작용을 확인. 공개 자료와 접근 권한이 있는 자료의 범위를 구분 |

읽을 수 없는 구간은 원본 위치와 함께 미확인으로 남긴다. 필요하면 지원되는 형식으로 내보낸 사본이나 해당 구간의 자료를 요청한다. 없는 내용을 추측해 복원 완료로 표시하지 않는다. 원본을 덮어쓰거나 변환본을 원본처럼 교체하지 않는다. 추출 도구 설치가 필요하면 기존 설치 동의 절차를 따른다.

## 원본과 새 화면 연결

`workshop/source-inventory.md`에 원본 파일·쪽/구간 → 새 페이지 ID·발표자 노트·자료 링크의 대응을 기록한다. 유지·분할·통합·노트 이동·승인 생략을 구분한다. 핵심 개념, 사례, 실습, 수치, 인용, 출처, 필수 문구의 행방을 추적할 수 있어야 한다.

화면의 텍스트는 편집 가능한 요소로 구성하고, 원본 그림/도표/실제 화면은 적절한 크롭·확대로 사용한다. 원본 화면의 시각적 정확성이 중요하면 해당 부분을 이미지로 보존할 수 있다. 모든 장을 그림으로 고정하거나 도표를 임의로 다시 그리는 방식을 강요하지 않는다. 원본의 클릭/단계 공개 의도를 파악해 필요한 장면에만 단계·비교·시연·실습 링크를 적용한다.

새 상호작용은 목표를 더 잘 전달할 때 제안한다. `scene-discovery.md`에 따라 원본 쪽/구간을 근거로 기능 체험을 추천하고 선택을 받은 뒤 전체 구성안에 반영한다. 예시 선택과 전체 구성안 승인을 구분한다. 참가자 화면·서버·AI API·설문을 자동으로 붙이지 않는다. 실제 기능과 시연 화면을 구분한다.

## 추가 조사와 구성안 확인

원본으로 충분한 내용은 유지한다. 빠진 맥락·최신 사실·공개 사례·설명에 필요한 근거만 범위에 맞춰 보충 조사한다. 원본 정보와 보충한 내용을 구분하고 출처·확인일을 남긴다. 개인의 경험·성과는 검색으로 만들어 채우지 않는다. 원본의 오류나 변경이 필요한 핵심 주장은 조용히 바꾸지 말고 구성안에서 수정 제안으로 표시한다.

전체 페이지 구성안에는 원본 위치, 화면의 한 메시지, 배치/내부 상태, 발표자/참가자 행동, 시간을 간결하게 보여준다. 변경·통합·생략과 미확인 자료를 설명하고 사용자 확인을 기다린다. 승인 전에는 자료 분석·텍스트 구성안과 동봉 일반 예시 체험까지만 진행한다. 이미 확인한 방향과 사소한 디자인 선택은 반복 승인받지 않는다.

## 내용 대조와 전달

제작 후 대응표를 원본과 다시 대조한다. 무엇이 화면에 남고 무엇이 대본으로 이동했는지, 중요한 내용·실습·수치·인용이 빠지거나 의미가 바뀌지 않았는지 확인한다. 승인된 생략과 누락을 구분한다. 추가한 내용은 별도 근거가 있어야 한다.

실제 브라우저 화면과 조작 검증도 수행하되 이것을 원본 내용 보존의 증거로 대신하지 않는다. 결과물·링크와 함께 편집 가능한 소스, 원본 대응표, 확인 불가 범위를 전달한다. 원본 파일·내부 대본·비공개 자료를 공개 폴더에 자동으로 올리지 않는다.
