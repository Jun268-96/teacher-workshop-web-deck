## 구조 선택

기존 템플릿을 폐기하거나 범용 PowerPoint를 구현하지 않았다. 신뢰된 HTML 템플릿에 작은 데이터 편집층을 얹었다. 편집/미리보기/요청/참여 서버는 정본과 권한을 분리한다. 사용자가 선택한 강의 형식과 승인된 구성은 유지한다. 위치는 반응형 흐름을 기준으로 슬라이드 안에서 옮기고 요소 간 겹침을 허용한다. 무한 캔버스는 아니다.

새로운 외부 계정이나 유료 AI API는 만들지 않았다. 노트·기획·실제 참가자 기록은 기본 공개 폴더/소스 ZIP에 섞지 않는다. Node 서버를 정적 Cloudflare 배포가 함께 배포한 것처럼 취급하지 않는다.

## 완료·경계

- **동작 구현 및 로컬 검증**: 위 편집·요청·데이터 패치·내보내기·다섯 참여 블록. 지원하지 않는 일반 브라우저에서도 작동한다.
- **실제 앱에서 관찰**: 이 환경의 IAB에서 주석 request 메서드는 감지됐으나 자동 조작 중 요청이 거절됐다. 자체 복사/파일 안내가 표시됐다. 실제 사용자의 주석 전송과 AI 코드 수정은 확인하지 않았다.
- **시연 예제**: 생성기의 `--example editor-live`. 원본 브랜드 레이아웃과 일반 참여 질문으로 기능을 시험한다. SEL 연수의 복원본/실제 사례로 소개하지 않는다.
- **외부 준비 필요**: 학교 태블릿이 접속할 HTTPS 서버, 실제 운영용 저장·인증·보존 설정, 공급자별 배포/다중 기기 검증. 이번에 새 공개 사이트/서버를 배포하지 않았다. 이전 공개 정적 예제도 이번 코드로 바뀐 것이 아니다.
- **미구현**: 주석에서 자동 소스 수정·저장·배포, 모든 HTML 프로젝트의 무조건 호환, 임의 코드 JSON 실행, 멀티탭 동시 편집 병합, 무한 자유 배치·타임라인, QR 이미지 생성, 바깥 발표 페이지와 참여 활동의 자동 연결, 추가 후보 참여 블록, 운영용 DB/DO 어댑터.

마이그레이션과 후속 우선순위는 [migration.md](migration.md), 실제 사용은 [editing-and-handoff.md](editing-and-handoff.md)와 [participation-runtime.md](participation-runtime.md)를 읽는다.


추가 E2E(2026-10-24): 사용자 UI 흐름 4개를 포함한 총 30개 검사를 통과했다. 복제/신규 페이지 주소로 다시 열 때 첫 페이지로 돌아가던 문제와, 데스크톱의 목차 호버 직후 클릭 시 닫히던 충돌을 수정하고 회귀 시나리오에 포함했다. 현재 localhost 예제도 같은 코드로 확인했다. 공개 배포 여부는 위 경계와 같다.

이동·동작 재검증(2026-10-24): 요소 자체 크기의 ±20% 제한 때문에 240px 드래그가 약 9px만 이동하던 문제와 첫 드래그 선택 문제를 수정했다. 슬라이드 기준 좌표, 새로고침/패널 전환 시 위치 재계산, 기존 좌표 호환을 추가했다. 동작 적용 직후 시험 모드와 즉시 표시되는 호버 안내를 제공하고 독립 HTML에도 스타일과 동작을 포함했다. 실제 이동 거리·겹침·복원·휴대폰 경계·동작 변경·독립 HTML을 확인하는 4개 검사를 추가했다.

모서리 크기 조절(2026-10-24): 선택한 텍스트/사진의 네 모서리를 마우스·터치로 끌어 크기를 조절한다. 반대 모서리 고정, 사진 박스 비율 유지, 한 번의 실행 취소, Escape/터치 취소, 발표용 HTML에서 편집 핸들 제거를 검증했다. 사진의 원본 비율은 `object-fit:contain`으로 보존한다. 사용자 추가 요청에 따라 텍스트 모서리 조절은 박스와 폰트를 같은 비율로 바꾸도록 갱신했다. 기존의 폰트 유지 검사를 실제 확대·축소와 폰트 한계·복원 검증으로 교체했다.

정렬 가이드(2026-10-24): 페이지 중앙/다른 요소의 가장자리·중앙에 가까워지면 가이드선과 자동 맞춤을 제공한다. Alt 자유 이동, 텍스트·사진, 터치 취소, 저장/복원, 발표용 HTML에서의 UI 제거를 검사한다. 브랜드 로고/연구회 이름은 기존 스킬 템플릿 기본값을 유지했다.
