## 구조 선택

기존 템플릿을 폐기하거나 범용 PowerPoint를 구현하지 않았다. 신뢰된 HTML 템플릿에 작은 데이터 편집층을 얹었다. 편집/미리보기/요청/참여 서버는 정본과 권한을 분리한다. 사용자가 선택한 강의 형식과 승인된 구성은 유지한다. 위치는 반응형 흐름을 기준으로 슬라이드 안에서 옮기고 요소 간 겹침을 허용한다. 무한 캔버스는 아니다.

새로운 외부 계정이나 유료 AI API는 만들지 않았다. 노트·기획·실제 참가자 기록은 기본 공개 폴더/소스 ZIP에 섞지 않는다. Node 서버를 정적 Cloudflare 배포가 함께 배포한 것처럼 취급하지 않는다.

## 완료·경계

- **동작 구현 및 로컬 검증**: 위 편집·요청·데이터 패치·내보내기·다섯 참여 블록. 지원하지 않는 일반 브라우저에서도 작동한다.
- **실제 앱에서 관찰**: 이 환경의 IAB에서 주석 request 메서드는 감지됐으나 자동 조작 중 요청이 거절됐다. 자체 복사/파일 안내가 표시됐다. 실제 사용자의 주석 전송과 AI 코드 수정은 확인하지 않았다.
- **시연 예제**: 생성기의 `--example editor-live`. 원본 브랜드 레이아웃과 일반 참여 질문으로 기능을 시험한다. SEL 연수의 복원본/실제 사례로 소개하지 않는다.
- **외부 준비 필요**: 학교 태블릿이 접속할 HTTPS 서버, 실제 운영용 저장·인증·보존 설정, 공급자별 배포/다중 기기 검증. 이번에 새 공개 사이트/서버를 배포하지 않았다. 이전 공개 정적 예제도 이번 코드로 바뀐 것이 아니다.
- **미구현**: 주석에서 자동 소스 수정·저장·배포, 모든 HTML 프로젝트의 무조건 호환, 임의 코드 JSON 실행, 멀티탭 동시 편집 병합, 무한 자유 배치·타임라인, QR 이미지 생성, 바깥 발표 페이지와 참여 활동의 자동 연결, 추가 후보 참여 블록, 운영용 DB/DO 어댑터.
