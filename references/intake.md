# 시작 질문

자료를 먼저 읽고, 이미 아는 답은 채운다. 아래를 그대로 매번 전부 묻지 않는다. 질문 도구가 있으면 관련 질문을 묶되 도구의 개수 제한을 지킨다.

## 필수 확인 두 항목

새 연수나 전체 재구성을 시작할 때 아래 두 항목의 답을 기존 대화·자료에서 먼저 찾는다. 명시된 답이 없으면 반드시 질문한다. 질문을 했다는 이유만으로 답을 받은 것으로 처리하지 않는다.

1. **실습/활동 여부**: “설명 위주로 진행할까요, 참가자가 직접 해보는 활동이나 실습도 포함할까요?” 실습에는 토의·역할극·활동지·수업 설계 등도 포함되며 컴퓨터 조작만을 뜻하지 않는다. 포함한다면 가능한 시간과 방식은 후속으로 구체화한다.
2. **필수 내용**: “반드시 포함해야 할 내용·사례·자료·문구가 있나요? 특별히 없거나 미정이면 그렇게 알려주세요.” 지정 주제·정책·교육과정·도구·개인 사례 등은 실제 답을 기준으로 기록한다.

두 질문은 다른 누락 조건과 함께 간결하게 묶어 묻는다. 시간만 확인하고 실습 여부를 추측하거나, 주제를 받았다는 이유로 필수 세부 내용까지 확인됐다고 간주하지 않는다. “없다/미정/추천해 달라/해당 판단을 맡긴다”는 유효한 응답이다. 그때는 추천과 가정을 구성안에 표시하고 확인받는다. 이미 답이 있으면 반복 질문하지 않는다. 일반적인 “알아서 해줘”만으로 두 항목을 건너뛰지 않는다. 답을 기다리는 동안 독립적인 자료 읽기·기초 조사는 가능하지만, 실습 구성이나 필수 내용을 임의로 확정하고 본격 제작하지 않는다.

## 핵심 질문

짧은 서두: “발표자료를 만들기 전에 빠진 내용만 알려주세요. 정하지 않은 항목은 제가 제안하겠습니다.”

1. 누구에게 무엇을 전달하나요? 주제, 사전 경험, 끝난 뒤 이해/실행할 한 가지.
2. 전체 시간이 얼마나 되나요? 설명 중심인지, 함께 따라 하거나 각자 결과물을 만드는 실습까지 포함하는지, Q&A·휴식 포함 여부. 15분을 기본값으로 가정하지 않는다.
3. 반드시 들어가야 할 내용·사례·자료·문구와 제외할 내용이 있나요? 바탕 자료·대본·기존 프로젝트도 확인하고, 충돌하면 정본을 정한다.
4. 어떻게 참여하나요? 큰 화면만 보는지, 개인 휴대폰/태블릿/노트북도 쓰는지, 설문·체험·Q&A 필요 여부.
5. 브랜드는 어떻게 하나요? 기본은 밝은 바탕·굵은 글꼴·색 테두리이며 로고·기관명은 없음. 요청받은 기관 정보만 적용하고, 기존 자료면 유지 범위 확인.

미정인 보통 선택에는 추천 하나와 이유를 제시한다. 작은 버튼·색상까지 질문하지 않는다. 답변을 받은 뒤 청중/목표/시간/연수 유형/운영 방식으로 짧게 정리한다. 주제만 주어졌으면 우선 청중·시간·실습 여부처럼 방향을 바꾸는 정보만 확인하고, 자료가 없다는 이유로 상세 대본까지 사용자에게 요구하지 않는다. “알아서 해줘”라고 했다면 실습 여부와 필수 내용의 미확인 사항을 한 번 명시적으로 묻는다. 나머지는 합리적인 가정을 밝히고 조사·구성안을 준비한다.

## 조건부 질문

| 조건 | 확인할 핵심 |
|---|---|
| 기존 자료를 웹으로 변환 | 원본 흐름을 유지할지 전달력 중심으로 재구성할지? 반드시 보존할 내용·표현과 제외할 내용, 여러 자료 중 정본, 추가 조사/업데이트가 필요한 범위? |
| 실습형 연수 | 참가자 기기·계정·사전 경험, 완성할 결과물과 완료 기준, 도구 설치/가입을 미리 할지 당일 할지, 개별/모둠 진행과 지원 방식? |
| 실제 제작 과정 | 원문 대화와 당시 화면이 있는가? 화면엔 요청 요약을 쓸지 원문을 쓸지? |
| 전후 비교 | 청중이 어느 차이를 알아봐야 하는가? 같은 위치·크기로 비교할 자료가 있는가? |
| 실시간 시연 | 발표자의 정확한 조작, 대기 시간, 실패하면 보여줄 캡처/녹화는? |
| 참여자 화면 | 발표를 따라 이동할지 자유 탐색할지? 설명 중에는 무엇을 띄울지? |
| 설문·공유 기록 | 익명 여부, 공개 범위, 저장 기간·초기화 방식? |
| 실제 AI API 대화 | 첨부 자료를 언제 반영할지, 대화 이력 유지, 자동 질문과 자유 입력의 관계? |
| 공개 배포 | 대상/공개 범위, 기존 계정·배포 도구 연결 여부, 비공개로 남길 자료? |

도구 설치 질문은 제작 전 일괄 질문에 넣지 않는다. 기능이 필요해진 순간 `doctor` 결과를 보고 [설치 안내](setup-and-deploy.md)를 따른다. 가입을 아직 안 했다는 이유로 구성·제작을 멈추지 않는다.
