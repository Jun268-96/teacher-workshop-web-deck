# 선택 모듈 계약

기본 템플릿은 정적 발표 화면 하나다. 투표·워드 클라우드·Q&A·사례 분기·마무리 한 줄의 선택형 참조 서버는 [참여 런타임](participation-runtime.md)에 구현되어 있다. 아래의 다른 모듈은 요청할 때 추가하는 계약이며 모두 구현된 기능 목록이 아니다. 현재 실제 연수의 서버/기록을 새 연수에 복사하지 않는다.

## 참가자 페이지·QR

접속 주소, 자동 따라가기/자유 탐색 전환, 설명 중 대기 화면, 휴대폰/태블릿 내비게이션을 먼저 정한다. QR은 공개 배포 주소를 가리킨다. 고정 단일 세션/코드별 세션은 운영 목적에 맞게 선택한다. 모형 QR이나 같은 브라우저 저장 공간으로 다중 기기 동기화를 증명하지 않는다.

## 실시간 설문·Q&A·링크 공유

서버가 상태를 소유하고 권한을 확인한다. 저장 → 전파 → 늦은 입장/새로고침 복원 → 재연결 흐름을 정의한다. 익명성·공개 집계·개별 기록 공개 범위를 구분한다. 동기화 화면은 진행자와 참여자 각각의 역할로 설계한다. 진행자 조작이 참여자 화면에 실제 반영되는 것을 보여준다.

테스트는 별도 세션/고유 표식 데이터로 한다. `qa/flows.json`에 격리된 컨텍스트를 추가하고 권한, 제출, 전파, 새로고침/늦은 입장 복원, 중복 제출, 정리까지 검사한다. WebSocket 단절·재연결이나 서버 재시작은 프로젝트별 통합 검사를 추가한다. 교사 개인의 실제 연수를 초기화하는 테스트는 하지 않는다.

## 파일 드래그·대화 시연

드래그 후 입력창 위에 첨부 카드가 보이고 삭제/재첨부가 가능하게 한다. 자동 대본 진행 트리거와 자유 입력을 구분한다. 빈 배경 클릭을 트리거로 했다면 입력창·버튼·링크·텍스트 선택을 제외한다. 실제 AI 호출과 대본 재생을 구분해서 소개한다. 실제 AI를 쓰면 첨부 시점부터 자료 맥락을 반영하고 이전 대화 이력을 유지한다. 임의 역할·답변 길이 제한은 사용자 요청이 있을 때만. 키는 서버 Secret이며 공개 JS에 넣지 않는다.

## 배포

실시간 모듈의 Worker 바인딩/DB/마이그레이션/Secret은 해당 프로젝트에 맞게 구성한다. 기본 하네스의 static-only 제한을 삭제해 억지로 배포하지 않는다. 서버 검사·데이터 보존·배포 후 다중 클라이언트 검사를 추가한다. 유료 호출과 운영 데이터 변경은 별도의 승인/범위가 필요하다.
