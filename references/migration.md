# 이전 버전에서 이동

## 새 연수

기존 폴더를 덮어쓰지 말고 새 스킬의 생성기로 새 프로젝트를 만든다. `/?edit=1` 편집 모드를 안내한다. 참여 모듈은 필요한 경우 `npm run live`로 로컬에서 확인하고 별도 운영 환경을 정한다. 일반 발표는 원래 주소다. 기존 웹 체험 사이트가 자동으로 업데이트됐다고 가정하지 않는다.

## 이미 만든 HTML 연수

1. 원본 소스/에셋/노트와 현재 동작을 백업하고 실제 구조를 읽는다. 다른 컴퓨터의 파일은 제공/확인 전에는 존재한다고 가정하지 않는다.
2. 현재 페이지의 영구 id를 유지한다. 편집할 요소에 페이지 안에서 유일한 `data-edit-key="heading"` 같은 키를 붙인다. 텍스트·이미지·유튜브·블록 유형을 구분한다. 사용자 입력이나 일시 결과와 정적 문구를 구별한다.
3. `scene-runtime.js`, `scenes.css`, `deck-model.js`, `editor-ui.js`, `editor.js`, `editor.css`와 아이콘 vendor/라이선스를 복사하고 **기존 코드의 초기화 뒤** 실행한다. WorkshopDeck의 currentId/go/refresh 어댑터를 실제 프로젝트에 맞춘다. 자동 생성기나 검색/치환으로 기존 화면 전체를 버리지 않는다.
4. 초기화는 한 번만 한다. DOM을 다시 그릴 때 사라지는 클릭 리스너는 위임하거나 컴포넌트 재초기화로 복구한다. 복제 페이지의 id/aria-controls/aria-labelledby/for 참조를 확인한다. 원래 HTML과 source templateVersion을 일치시킨다.
5. 현재 탭·동작·미디어·전체화면·단축키를 재검사한다. 이 템플릿과 다른 DOM이면 그대로 호환된다고 말하지 않는다. 임의 HTML/JS를 편집 JSON으로 실행시키지 않는다.
6. 기존 연수에 참여 서버를 붙이려면 별도 서버 계약/배포·보존 검증을 추가한다. 현재 운영 세션을 새 템플릿의 시험 데이터로 사용하지 않는다.

## 파일 전달

편집 JSON에는 변화와 노트가 들어 있으며, 원래 신뢰된 HTML 템플릿이 필요하다. 기존 schema 1 편집본은 그대로 읽으며 장면이 들어간 새 편집본에는 현재 scene-runtime.js와 editor-ui.js도 필요하다. 발표용 HTML은 현재 상태를 굳힌 독립 파일이다. 발표용 파일을 편집 정본으로 되돌려 가져오는 역변환은 이번 범위가 아니다. 새 AI 대화에는 소스 ZIP과 편집/요청 JSON을 함께 제공한다.

기존 스킬 설치 폴더는 백업 후 갱신한다. 사용자의 추가 지침·에셋·코드와 충돌하면 먼저 비교해 보존한다. 설치 갱신이 이미 배포한 연수나 다른 프로젝트의 코드/데이터를 자동으로 바꾸지는 않는다.

## 다음 우선순위

1. 실제 사용하는 연수 한 편에 어댑터를 적용해 대상 지정 범위와 대본·시간 동기화를 검증한다(원본을 제공받은 뒤).
2. 승인된 운영 대상에 영속 DB/Cloudflare DO 어댑터, HTTPS·운영 인증·보존 정리와 다중 기기 공개 검증을 추가한다.
3. 페이지별 참여 블록과 바깥 슬라이드 진행 연결, QR 생성, 더 복잡한 사례 분기 소스 수정 검토를 추가한다.
4. 사용 증거가 쌓인 뒤 멀티탭 충돌 해결·그룹 정렬·일괄 스타일 등 편집 기능을 선택적으로 늘린다.
