# 기본 디자인 템플릿

`assets/starter-deck/`를 사용자 프로젝트로 복사한다. 이 스킬 자체의 템플릿은 개별 연수를 만들 때 수정하지 않는다.

```sh
node <skill-dir>/scripts/create-deck.mjs --dest <new-project-dir> --name <new-worker-name>
```

배포 대상 미정이면 `--name`을 생략한다. 기존 폴더는 덮지 않는다. Node가 없으면 파일 도구로 폴더를 복사하고 설치 안내로 이어간다.

- `public/`: 브라우저에서 직접 열거나 서버로 제공할 HTML/CSS/JS와 브랜드 에셋. 외부 CDN 없이 기본 발표가 동작한다.
- `config.js`: 제목, 발표자, 기관, 타이머 시간, 로고, 캐릭터 사용, 자료 링크.
- 7개의 **레이아웃 예시**: 표지, 장 제목, 한 문장, 화면 비교, 실제로 작동하는 추첨/요청 메모 시연, 자료 카드, 마무리. 템플릿의 시간은 미정(`durationMinutes: null`), 타이머는 꺼짐이다. 원본의 시간은 자동 승계하지 않는다. 사용자가 현재 시간을 확정하고 타이머를 원할 때 설정한다. 이는 작성법 설명용 예시이고 실제 성과 사례/원본 과거 화면이 아니다. 필요한 형식만 골라 새 내용을 채운다.
- `harness/`, `qa/flows.json`: 검사·캡처·동작 시나리오·배포 게이트. `public/` 바깥에 있어 업로드되지 않는다.
- `workshop/`: 브리프·구성·출처·대본과 로컬 요청함 사용 안내. 발표물과 함께 공개하지 않는다.
- `npm run dev`: 기본 정적 미리보기와 로컬 편집 요청함을 함께 제공한다. `AGENTS.md`/`CLAUDE.md`는 같은 폴더의 에이전트에 사용법을 안내한다. `.workshop-editor/inbox/`는 첫 저장 때 생성하며 공개/커밋/소스 ZIP에서 제외한다. [로컬 요청함](local-editor-inbox.md)을 참조한다.

기본 디자인: Pretendard, 종이색 #fffdf7, 잉크 #19262a, 분홍 #df8288, 노랑 #f0da48, 연두 #bfdc52. **기관명과 로고는 비워 둔다.** `config.js`의 `host`, `logo`, `logoAlt`는 빈 문자열이다. 표지 기관 영역과 고정 로고는 비어 있으면 숨기고, 파비콘은 일반 문서 아이콘을 사용한다. 사용자가 제공하거나 요청한 경우에만 해당 값을 채운다. **캐릭터는 기본 비활성화**이며 요청 시 `modules.mascots: true`로 반디·디디를 켠다. 캐릭터를 끈 표지·마무리는 텍스트 중심 배치를 사용한다. 글꼴의 동봉 라이선스는 유지한다. 동봉된 기존 브랜드 에셋은 요청 시 선택적으로 사용하는 자료이며 새 발표자료에 자동 적용하지 않는다. 다른 기관의 소유물처럼 소개하지 않는다.

기본 런타임: 고유 ID/해시 복원, 푸터 바깥 페이지 이동, 목차 호버/포커스/터치, `F` 전체화면, 확정 시간에 설정하는 선택적 타이머, 탭, 동작 줄이기. 캐릭터 반복/호버 반응은 요청 시에만 사용한다. 화면 수정 뒤 QA 시나리오도 **의도한 행동에 맞춰** 갱신한다. 검사를 통과시키려고 기능 요구를 없애지 않는다.

참가자 페이지·QR·설문·실시간·파일 첨부·AI API는 기본으로 넣지 않는다. 요청될 때 필요한 모듈을 구현하고 `live-modules.md`의 검사를 추가한다.
