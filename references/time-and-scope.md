# 시간의 출처와 현재 적용 범위

자료에 시간이 적혀 있다는 사실과, 사용자가 **이번 작업의 시간으로 확정했다는 것**을 구분한다. 새 연수·자료 재구성·스킬 테스트에서는 원본의 시간표를 자동 승계하지 않는다.

## 브리프에 기록할 세 가지

| 상태 | 근거 | 구성할 때의 처리 |
|---|---|---|
| 현재 확정 | 이번 작업에 대한 사용자의 명시적 시간 또는 기존 시간을 유지하라는 응답 | 확인된 범위와 Q&A·휴식 경계에 맞춰 배분 |
| 자료에만 있음 | 원본 제목·타이머·페이지 seconds·과거 대본·다른 회차/작업의 대화 | 출처와 함께 참고 이력으로 기록. 현재 목표 시간은 미정 |
| 미정 | 시간 언급 없음, 사용자가 미정으로 지정, 이전 제한을 철회 | 내용·시연·참여 행동 중심으로 구성. 임의의 총시간/마감 시각을 넣지 않음 |

`workshop/brief.md`에 **현재 시간 상태 / 확정 시간과 사용자 근거 / 원본에 남은 시간과 위치 / Q&A·휴식 경계**를 나눠 적는다. 원본의 시간 수치를 지우거나 역사적 자료를 고치지는 않는다. 프로젝트 제작에 걸린 시간, 수업 속 학생 활동 시간, 발표용 타이머는 서로 다른 수치다.

같은 현재 작업에서 이미 명시적으로 확인했고 이후 바뀌지 않은 시간은 반복 질문하지 않는다. 반대로 오래된 대화의 지시가 이번 새 테스트/재구성에도 적용된다고 추정하지 않는다. 최신 사용자 정정이 이전 수치보다 우선한다.

## 시간이 미정일 때

- 시간 정보가 필요한데 원본에만 있으면 한 번 짧게 확인한다. 예: “원본에는 15분으로 적혀 있습니다. 이번에도 유지할까요, 시간 미정으로 내용부터 잡을까요?” 이미 미정이라고 답했으면 다시 묻지 않는다. 답을 기다리는 동안 자료 읽기와 장면 추천은 계속할 수 있다.
- 전체 구성안은 페이지별 메시지·자료·장면·발표자/참가자 행동·활동의 완료 기준을 먼저 제시한다. 시간 열은 `미정`으로 두거나 생략하고, 총시간과 누적 시각을 확정하지 않는다. 시간 미정 자체가 구성안 확인을 막지는 않는다.
- “15분 안에” 같은 미확정 제약을 이유로 대화를 7회에서 2회로 줄이거나 기능·실습을 건너뛰지 않는다. 중복·가독성·학습 목표에 따른 편집 제안은 가능하지만, 시간 압축과 구별하고 중요한 변경은 구성안에 표시한다.
- 필요 분량을 산정해 달라는 요청이 있으면 설명·조작·입력·AI 대기·확인에 근거한 **예상 범위**를 제안할 수 있다. 추정의 조건을 밝히고 이를 확정 시간이나 다른 고정 기본값으로 바꾸지 않는다.
- 시간이 확정되지 않은 새 결과물은 시간 표기를 숨기고 타이머를 끈다(`durationMinutes: null`, `modules.timer: false`). 확인된 시간과 타이머 사용 의사가 있으면 그때 설정한다. 기존 운영 자료의 시간 표기를 바꾸는 것은 별도 수정 범위이며, 분석·테스트만 요청받았을 때 원본까지 고치지 않는다.

## 판단 예시

| 입력 | 올바른 판단 |
|---|---|
| “이 자료로 새로 구성해줘”, 원본 표지에 15분 | 자료의 15분은 참고 이력. 이번 시간은 미확정 |
| “이 자료로 60분 연수를 만들어줘” | 현재 확정은 60분. 원본 시간표를 맞추려 하지 않음 |
| “기존 15분 구성과 시간을 그대로 유지해줘” | 명시적으로 승계했으므로 15분 적용. 재질문 불필요 |
| “기존 자료를 넣었다고 생각하고 스킬을 테스트해봐” | 새 테스트의 조건을 판단. 예전 연수 시간 자동 승계 금지 |
| “시간 미정으로 전체 구성안부터” | 시간 질문을 반복하지 않고 내용 중심 구성안 제시 |
| 현재 작업에서 90분으로 확인한 뒤 “이어서 수정” | 아직 유효한 90분은 유지 |
| “누적 200시간 작업”이라는 본문 | 사례 속 제작 시간. 연수 길이로 해석하지 않음 |

이 예시는 판단 기준이며 독립된 모델 평가의 통과 기록은 아니다.
