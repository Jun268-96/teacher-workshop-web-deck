# 화면과 조작 기준

## 시각 언어

새 연수의 기본은 동봉된 반올림 브랜드다. 밝은 바탕, 굵은 한국어 제목, 페이지별 분홍/노랑/연두 프레임, 여유 있는 공간, 픽셀 로고. 캐릭터는 기본적으로 없고, 사용자가 요청할 때만 선택적으로 추가한다. 기존 프로젝트는 사용자 지정 디자인을 유지한다. 다른 기관이면 설정과 에셋을 교체한다. 로고를 모든 페이지에 같은 크기로 강제하지 않는다.

대본과 화면을 분리한다. 한 화면에서 전달할 한 문장/조작/비교만 남긴다. ‘학급 경영’, ‘제작 과정’처럼 구체적인 짧은 제목을 쓴다. 장식용 영어·반복 제목·임의의 추상 그룹명·복원 버전 번호는 청중에게 도움이 될 때만 노출한다. 장 제목이나 한 문장만 있는 페이지도 허용하며 푸터는 유지한다.

긴 내용을 작은 글씨로 압축하지 않는다. 부가 내용은 대본으로 보내거나 장면을 나눈다. 모든 것을 토글/모달에 쌓지 않는다. 실제 화면은 필요한 부분을 크게 크롭한다. 전후 비교는 같은 영역·같은 배율·다른 상태가 드러나게 한다. 캡처를 실제 동작처럼 꾸미지 않는다.

## 조작 계약

- 푸터 이전/다음·PageUp/PageDown은 바깥 페이지. 내부 탭/상태 변경과 섞지 않는다.
- 화살표는 기본 페이지 이동. 탭 위에서는 탭의 표준 키 조작을 따른다. 입력/편집 중에는 페이지 단축키를 가로채지 않는다. 버튼에 포커스가 있다는 이유만으로 모든 페이지 화살표를 막지 않는다.
- 목차는 페이지 숫자의 호버·포커스·터치에서 열고 키보드로 선택 가능. 포인터가 패널로 이동하는 동안 닫히지 않게 한다.
- 고유 ID로 해시 복원. 제목 변경/페이지 삽입이 기존 동작을 깨지 않도록 한다.
- 전체화면은 문서 루트를 대상으로 해 타이머·QR 등 필요한 고정 도구도 유지한다. 사용 환경에서 허용되지 않으면 오류를 숨겨 완료로 표시하지 않는다.
- 제목/썸네일이 이미 링크면 동일한 ‘직접 열기’ 버튼 생략. 대화 보기와 원문 전체가 겹치면 한 진입점으로 합친다. 선택 기능은 실제 필요가 있을 때만 노출한다.
- 로고·타이머·QR·푸터가 제목이나 조작 영역과 겹치지 않도록 짧은 프로젝터 높이에서도 확인한다.

## 모션

과정·시간·원인/결과를 드러내는 모션은 반복/재생 가능하게 한다. 사용자가 캐릭터를 요청했다면 조용한 마스코트 루프와 반응도 허용하되 본문을 가리거나 시선을 계속 빼앗지 않는다. 호버 효과는 포커스·터치에서도 쓸 수 있게 하고 reduced-motion에서 핵심 내용을 유지한다. 작은 반응을 추가할 때 기존 클릭/초기화 기능을 보존한다.

## 장면별 검토
